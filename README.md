# Winter Escape 2026

中文、移动端优先的欧洲冬季旅行静态网站。无需构建、登录或后端。

## 本地预览

在仓库目录运行：

```sh
python3 -m http.server 8000
```

在本机浏览器访问 `http://localhost:8000`。iPhone 可通过同一局域网的电脑 IP 与端口访问；云环境请使用平台提供的端口转发。也可直接打开 index.html，但建议通过 HTTP 访问，以保持稳定的本地存储来源。

## Cloudflare Pages

连接此 GitHub 仓库，选择静态站点：框架预设 None，构建命令留空，输出目录填写 `.`。部署根目录包含 index.html、style.css、script.js。无需环境变量。

## 功能与数据

- 12 月 20—31 日日期切换，四个固定航班与已确认交通；所有航班使用用户给定的当地时间。
- 每日景点、酒店、交通与备注可编辑，支持多个条目与删除；未确定的预订与班次不预填。
- 支持 EUR、ISK、PLN、CHF；新增支出按日期默认币种，编辑保留原币种。每日显示当地币种合计及其他原币支出。
- 全程欧元估算使用手动设置的「1 外币 = X EUR」汇率，不提供实时汇率。缺失所需汇率时不显示完整总额；各汇率标注手动更新时间（巴黎时间）。
- 继续使用原 localStorage 键与版本 1 JSON，兼容旧 EUR/PLN 数据；汇率作为可选字段保存及导出。更新前仍建议导出备份。
- 可增删与勾选的清单，JSON 导入导出（版本 1，最多 5MB）。导入替换自定义数据前会确认，固定航班不受影响。
- 自定义内容保存到当前来源下的 localStorage；不向服务器发送，不同步其他浏览器或设备。清理存储、切换域名、浏览器或部署地址可能导致原数据不可见。更新页面不能保证其他设备保留数据，请先导出备份。
- 微信下载可能受浏览器限制，必要时使用“在 Safari 中打开”导出。照片和地图链接由用户自行填写；外部资源可能受网络限制。
- 封面为本地 CSS 插画；中文字体在网络可用时加载，失败使用系统字体。

项目不包含真实酒店预订、票务购买或航班查询服务；出发前应向承运方核对实际运营情况。

## 交通倒计时

`traffic.js` 使用 IANA 时区将当地日期时间转换为绝对时间戳，独立于访客设备时区。首页每秒选取尚未出发的最近一程；每日卡片按计划出发/抵达显示状态，不代表实际运营。最后一程计划抵达前保持进行中，之后显示旅行结束。没有时间的交通保留“待确认”，不参与下一程排序。

固定交通可修改计划出发/抵达日期时间与各自时区；自填交通通过原交通编辑框填写。跨午夜必须选正确日期。原始航班展示信息保留，编辑后的计划时间单独显示。时间覆盖保存为可选 `trafficOverrides` 字段，自填交通时间随原条目保存，沿用原 localStorage 键，JSON 备份兼容旧数据。

时区与计划状态回归测试：`node tests/traffic.test.cjs`。

## 已确认共享预订

`bookings.js` 包含 Einholt 公寓酒店与奥斯威辛纪念馆的公开行程事实，不包含门禁密码、票号、条码、二维码、订单号或 PIN。酒店在 12月21—24日的「今晚住哪里」统一展示，25日仅保留退房提醒与可展开的原始预订详情，入住、退房和纪念馆预约均按各自当地时区每秒倒计时。每日行程按「交通信息 → 今日游览 → 今晚住哪里 → 每日备注」展示。已填出发时间的交通按绝对时间排序，待确认交通列在后方。12月26日 W61540、机场至纪念馆和参观后前往克拉科夫的交通统一列在交通模块，纪念馆门票与入场倒计时列在今日游览。

账本以稳定预订 ID 初始化一次：住宿为订单总价 460.64 EUR（实际付款待核实），纪念馆为 0 PLN。平台承担 30.47 EUR 与差额 430.17 EUR 仅说明，不重复计入费用。已有同名记录或对应酒店总价记录会复用；不会改变用户原金额。初始化标记随 JSON 导出，用户后续修改或删除费用不会在刷新时自动重加。原 localStorage 键不变，旧记录与本机编辑保留。免费项目不要求设置汇率。

## 12月26日计划与私密门票

显示计划顺序：W61540抵达WMI → 前往克拉科夫 → 酒店或寄存点放行李 → 前往奥斯威辛 → 13:30预约参观。两段交通与寄存信息默认待确认，可编辑并随原 localStorage/JSON 保存；不自动记入未知费用。旧路线的本机时间覆盖仍保留，但不用于新路线倒计时。

「查看门票PDF」使用普通链接在新标签打开用户提供的 Google Drive 文件预览页。文件权限、登录和访问申请由 Google Drive 处理，网站不下载、存储或代理真实PDF。微信无法预览时可在 Safari 中打开。链接跳转已可测试，文件本身与账户访问权限不由此静态站验证。不要将 `bilety.pdf` 放进公开仓库或 Pages 输出目录；`.gitignore` 只降低误提交风险，不构成访问控制。
